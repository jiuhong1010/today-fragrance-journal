# 今日用香志｜微信小程序 MVP 0.1

这是一个可直接导入微信开发者工具的原生小程序工程，不需要 npm、后端或网络接口。

## 导入

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前文件夹：`/Users/jiuhong/Documents/ChatGPT/vibecoding`。
4. AppID 暂时使用测试号或在 `project.config.json` 中替换为自己的 AppID。
5. 编译即可查看今日、推荐、香柜和闻香页面。

## 快速体验

新安装时香柜为空：

1. 进入“香柜”。
2. 点击“添加一瓶”。
3. 从内置资料中添加至少 2～3 款香水。
4. 回到“今日”，选择目标、场合和体感，点击摇一摇按钮。
5. 在推荐页测试“换一瓶”“记下今天”和叠香入口。

当前内容包来自 `content/`，50 款香水与 30 组叠香仍是开发审校初稿。代码已允许 `draft` 叠香用于开发预览；正式发布前应将内容补齐官方来源并把状态改为发布状态，同时接入 manifest 发布门禁。

## 工程结构

- `pages/today`：今日选香与传感器/按钮入口。
- `pages/result`：推荐结果、理由、喷法、换一瓶、记录和叠香。
- `pages/wardrobe`：本地香柜和最近记录入口。
- `pages/add`：内置香水添加与自定义香水表单。
- `pages/fragrance`：按日常感觉搜索 50 款香水，并提供 4 个大方向、14 个家族和一分钟科普。
- `pages/records`：最近 30 次用香记录。
- `pages/settings`：本地数据说明、减少动态效果和清除数据。
- `utils/storage.js`：本地数据、版本字段和清除机制。
- `utils/content.js`：静态内容读取与推荐规则 v2；同一候选轮次不立即重复，结果页可继续摇动换一瓶。
- `components/`：适配微信原生胶囊安全区的顶部栏、统一底部导航、真实返回入口与四维香气雷达图。
- `assets/icons/`：同一笔画规范的本地图标资源。
- `assets/perfumes/`：50 款内置香水各自对应的本地实物瓶身参考图。
- `assets/bottles/`：自定义香水与空状态使用的原创占位瓶视觉。
